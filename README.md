# Car Consórcios

Landing page responsiva e moderna para uma empresa de consórcios automotivos, desenvolvida com React + Vite e preparada para deploy em plataformas como Vercel e Netlify.

## ✅ O que foi implementado

- Landing page profissional e responsiva
- Seções de destaque: hero, planos, vantagens, depoimentos, FAQ e contato
- Sidebar com comportamento dinâmico
- Formulário de contato integrado ao FormSubmit
- Página de agradecimento após o envio
- Estrutura componentizada em React
- Build otimizado com Vite

## 🛠 Tecnologias

- React
- Vite
- CSS3
- Font Awesome
- FormSubmit

## ▶️ Como rodar localmente

```bash
npm install
npm run dev
```

A aplicação ficará disponível em:

```bash
http://localhost:3000
```

## 🧪 Build para produção

```bash
npm run build
```

## 📬 Formulário

O formulário está integrado ao FormSubmit e envia mensagens para o e-mail configurado. A página de agradecimento foi criada em [thanks.html](thanks.html).
