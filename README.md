# Car Consórcios

Landing page responsiva para uma empresa de consórcios automotivos.

## Tecnologias

- HTML5 Semântico
- CSS3
- CSS Grid Layout
- Flexbox
- Media Queries
- Font Awesome

## Recursos

- Layout responsivo
- Navegação suave
- Sidebar sticky
- Interface moderna
- Efeito glassmorphism
- Estrutura semântica
- Cards responsivos
- Formulário de contato
- Grid Template Areas

## Objetivo

Praticar desenvolvimento front-end moderno utilizando Grid Layout e responsividade.
